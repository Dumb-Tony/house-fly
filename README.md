# House Fly

[Play House Fly](https://dumb-tony.github.io/house-fly/)

One fly, one human, one breakable lamp. A bounded M1 prototype of irritation, dodging and deliberately baited collateral damage.

Open `prototypes/m1/index.html` directly in a desktop browser to play offline. No installation, build, network or external assets are required. WASD/arrows fly, Space bursts, E lands/takes off, Escape pauses, R restarts, F3 toggles debug information.

Read [implementation and tuning](docs/IMPLEMENTATION_M1.md), [M1 acceptance procedure](docs/PROTOTYPE_M1.md), [playtest evidence](docs/PLAYTEST_LOG.md), or [design](GDD.md). Run `node tests/simulation.cjs` from this folder. GitHub Actions repeats these checks and publishes only the prototype folder to Pages.

Fresh-player enjoyment and comprehension gates remain pending. This prototype does not authorize or implement M2. Private source conversation notes stay local and are ignored by Git.
